# Careme Android TWA

This project is generated by Bubblewrap from `twa-manifest.json`.

The PWA manifest at `../internal/static/manifest.webmanifest` cannot declare Android build settings. Bubblewrap reads it for install metadata such as name, colors, icons, shortcuts, protocol handlers, file handlers, and launch handling.

Bubblewrap 1.24.1 generates a project targeting Android 15. Google Play requires new apps and app updates to target Android 16 (API level 36) starting August 31, 2026, so Careme patches the generated `app/build.gradle` to target API level 36. The location-delegation dependency contributes the Android location permissions to the merged application manifest.

After running Bubblewrap regeneration or update commands, run:

```sh
./apply-bubblewrap-patches.sh
```
